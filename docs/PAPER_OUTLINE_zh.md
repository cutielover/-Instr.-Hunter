# 论文目录草案（中文）— 完整方案版

**拟定题目**：一种微处理器隐藏指令分析工具的设计与实现  
**工程基础**：riscv-sifter（RISC-V + AArch64 注入扫描，memcage / ptrace，Capstone 反汇编对照）  
**参考论文**：iScanU（Erik van der Kouwe，RISC 上可移植未公开指令扫描；ptrace + memcage 双路径）

> **说明**：本目录按**你期望的完整方案**编排（含**实机硅后验证**与**通用扩展 / 配置驱动代码生成**）。仓库当前实现进度与论文定稿之间的缺口，在写作时用「已完成 / 进行中」诚实标注，而不是把论文范围缩成「仅仿真」。

---

## 摘要

- 问题：未文档化 / 异常指令对可靠性与安全的影响；多 ISA、多实现来源下第三方可复现扫描与扩展需求。  
- 方法：用户态单条注入 + 信号判定 + 反汇编器作为 ISA 视图 ground truth；**memcage 与 ptrace 可插拔**；**统一编排核心 + 架构后端**；**面向新 ISA 的配置描述与模板化代码生成（或半自动生成 + 人工加固 memcage）**，降低接入成本。  
- 结果：**仿真 / 容器环境下的回归与受控验证** + **真实硬件上的扫描实验与统计**；与 iScanU 对照体现工具链代际与扩展性；可选 **MIPS** 等扩展 ISA 与 **x86 相关工作（Domas 等）** 的定位讨论。  
- 关键词：隐藏指令；指令空间扫描；memcage；ptrace；Capstone；代码生成；可扩展性；RISC-V；AArch64；实机验证。

## 第 6 章 实验与评估

评估分**三层**（与 `docs/EVALUATION_MATRIX.md` 一致），论文叙述中避免把任一层偷换为「唯一真理」：

6.1 **层 A — 受控与仿真环境**：Docker / QEMU user；**吞吐**、memcage vs ptrace、受控注入（如 QEMU 行为修改）证明管线有效  
6.2 **层 B — 实机硅后实验（论文主证据之一）**：**RISC-V 与/或 AArch64 真实硬件**上的同协议扫描；记录 **CPU 型号、步进、微码（若适用）、内核版本**  
6.3 **层 B 与层 A 对照**：相同编码子集或相同 random seed 下，**分类一致性 / 差异分析**（哪些差异来自 user-mode 仿真、哪些可能来自硅片）  
6.4 **层 C — 扩展性 / 生成框架验证**：从**新增配置文件**到**可运行探测器**的**时间或代码量**；可选 **MIPS** case study  
6.5 分类统计与人工复核协议（H/D/T/X；特权与 `ILL_PRVOPC` 单独讨论）  
6.6 讨论：ground truth 局限、伦理与负责任披露
